# Naver Works Clone Frontend

네이버웍스의 협업 경험을 참고해 만드는 개인 포트폴리오용 기업 협업 플랫폼의 프론트엔드 저장소입니다.
실제 네이버웍스의 내부 구현이나 디자인을 복제하는 프로젝트는 아닙니다.

> 현재 상태: 개발 준비 단계. 아래 기술과 기능은 계획이며, 구현 완료를 의미하지 않습니다.

## 역할

Spring Boot API와 연동하는 사용자·관리자용 웹 화면을 제공합니다.
백엔드 저장소는 별도 Git 저장소로 관리하며, API 계약을 기준으로 통합합니다.

## 주요 화면 범위

- 로그인 및 사용자 프로필
- 조직도, 구성원 검색, 즐겨찾기
- 1:1·그룹 메신저, 실시간 메시지, 읽음 상태
- 오늘 일정, 개인·조직 일정, 회의실 예약
- 일반 사용자와 관리자 역할에 따른 메뉴 및 대시보드

관리자 화면은 단순한 UI 토글이 아니라, 백엔드의 실제 역할 기반 권한 검증과 함께 동작하도록 설계합니다.

## 예정 기술 스택

| 영역 | 계획 |
| --- | --- |
| Framework | Next.js, TypeScript |
| Styling | Tailwind CSS, shadcn/ui |
| Server state | TanStack Query |
| Client state | 필요 시 Zustand |
| Real-time | WebSocket / STOMP 기반 백엔드 연동 |

## 개발 방향

- API 오류, 로딩, 빈 상태를 화면별로 명확히 처리합니다.
- 역할 기반 접근 제어는 프론트 메뉴 노출뿐 아니라 서버 응답을 기준으로 처리합니다.
- 실시간 연결 상태와 재연결 UX를 실제 백엔드 정책에 맞춰 구현합니다.
- 특정 서비스 UI를 그대로 복제하지 않고, 협업 기능에 맞는 자체 UX를 구성합니다.

## 실행 방법

프로젝트 초기화 후 Node.js 버전, 패키지 매니저, 환경변수와 실행 명령을 이 문서에 추가합니다.
